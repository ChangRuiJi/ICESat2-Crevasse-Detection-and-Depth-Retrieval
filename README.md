# ICESat-2 Crevasse Detection and Depth Retrieval

This repository is associated with our study on automated crevasse detection and depth estimation from ICESat-2 ATL03 photon data over the Greenland Ice Sheet (GrIS).

## Overview

The study presents an automated method for mapping crevasse depth distributions using ICESat-2 ATL03 data. The workflow consists of three main steps: candidate crevasse region selection, glacier surface photon retrieval and reconstruction, and crevasse extraction and depth estimation.
